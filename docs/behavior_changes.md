# 원본 보존 및 향후 변경 원칙

현재 `experiments/*/original`에 옮긴 Python 파일은 과거 코드를 수정하지 않은 원본이다.
2019년 로컬 원본 32개 파일은 SHA-256 해시 비교를 통해 복사본과 내용이 같음을 확인했다.

- 파일 내용과 학습 로직을 변경하지 않았다.
- 코드와 결과의 상대경로가 유지되도록 원본 디렉터리 구조를 `original` 아래에 보존했다.
- 데이터셋 원본과 캐시만 제외하고 체크포인트, 생성 이미지, 그래프, CSV를 코드와 같은 `original` 트리에 옮겼다.
- `.spyproject`, `__pycache__`, 압축 파일과 논문 PDF는 실험 실행 결과가 아니므로 이전하지 않았다.

향후 실행 호환성을 위한 수정이 필요하면 원본을 덮어쓰지 않고 별도의 wrapper 또는 정리본을
만든다. 알고리즘 동작에 영향을 주는 수정은 이 문서에 기록한다. 특히 과거 코드의 loss 누적
방식, ACGAN logits 처리, BAGAN label conditioning, 배치 단위 평가 지표는 설명 없이
변경하지 않는다.
